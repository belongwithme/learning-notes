# 英语学习每日清单与复测优化 PRD 审核稿

版本：0.3

日期：2026年10月13日

状态：本次修订待用户审核；实现进度另见实施记录

适用模块：英语学习首页、词库学习、历史课程与分析、词条详情

本次优化让用户打开英语模块后，只需跟随一个明确的下一步完成学习：开始或继续学习，读讲解与短文，完成练习，查看结果并确认下次复习。首页依据数据库里的学习记录推荐行动；历史课程和分析报告用于回看，不要求用户先读报告、选周期或辨认课程版本才能开始。

本稿是[英语学习个性化分析与巩固训练 PRD](./英语学习个性化分析与巩固训练PRD.md)的增量审核稿。原有课程内容质量、个人口令、记录保存、纠错与生成授权规则继续适用。本文明确变更的入口和展示规则，审核通过后作为该部分的新要求；其他规则不重复定义。开发前先形成技术方案和对应执行清单，本稿不代表已经实现、发布或授权新增定时任务。

## 一 本次方案与修订重点

建议先实施以下三个能力，完整词条档案和更深入的学习分析放到后续阶段。

| 首期能力 | 用户能得到的结果 |
| --- | --- |
| 统一学习首页 | 突出一个可立即开始的行动，直接进入应继续的阶段；其他内容可展开选择 |
| 历史课程状态 | 找到旧课程，知道学到哪一步，直接继续；今天没生成报告也能访问历史 |
| 跨日复测流程 | 从练习结果确认复测安排，到期后完成新语境题目，分清已作答与独立通过 |

首期沿用“Codex 备课，网站学习与反馈”。网站依据已有记录计算清单与进度；新讲解和新题目仍通过既有 Codex 工作流生成并保存。

本版以“用户能否独立完成一次学习”为评审重点，保留一个主行动、逐步保存和结束回执，补齐词库掌握程度筛选、历史返回路径与无引导走查。具体规则仍为审核稿，文末列出审核要点。

从产品流程看，当前主要障碍是入口分散、学完后的下一步不明确，以及缺材料时需要切换到 Codex。首期将已有材料的学习收敛为站内连续流程；只有确实需要新材料时才出现备课说明。是否已经简单易用，必须通过第九节的实际走查确认。

## 二 现状与问题

### 当前数据基础

2026年10月13日本次讨论中的生产数据库只读快照如下。数字仅用于说明当前阶段，不是上线时的固定数据或长期趋势。

| 数据 | 当前快照 | 能说明什么 |
| --- | --- | --- |
| 学习自评 | 394 次，覆盖 274 个词条、3 个北京时间自然日 | 可识别用户近期觉得不稳的词，观察重复自评 |
| 已保存分析课程 | 15 份，分别属于 10 月 10 日和 10 月 12 日 | 有可继续利用的历史学习内容 |
| 课程学习事件 | 2 条学习步骤记录、1 条提示记录 | 有少量学习交互，不代表完成了两门课程 |
| 已保存作答与复测安排 | 均为 0 | 目前不能计算实际答题正确率或验证跨日保留情况 |

现有代码已经支持课程、学习步骤、客观题作答、提示使用、困难反馈、复测安排和基础统计。本次在这些能力上完善入口、状态展示和后续行动，不重新建设一套学习系统。

### 用户遇到的问题

1. 分析页默认展示“今天”。今天没有报告时只提示“本期尚未生成”，已有历史课程不够显眼，容易被理解为历史数据丢失。
2. 历史列表主要展示标题和已答题数，用户不容易判断该继续讲解、精读还是答题，也看不清后续复测。
3. 词库自评、课程进度和复测安排分散，用户需要自己决定先处理什么。
4. “为这个词生成过课程”“学完课程”“通过复测”是不同事实，目前缺少统一、直观的呈现。
5. 当前数据主要来自自评，首期应帮助用户进入学习和作答流程，避免在证据不足时给出精确能力分数或遗忘概率。

## 三 目标和范围

### 首期目标

- 用户进入英语首页后，无须先理解词库、课程和周期分析之间的关系，可以直接开始或继续学习。
- 每一步只有一个主要推进动作；用户能看清是否保存成功、失败后如何继续以及完成后去哪里。
- 已保存的历史课程始终可找到，能恢复已保存的学习阶段和答案。
- 清楚区分内容准备、学习完成、独立作答和跨日复测证据。
- 复测缺少材料、题目有误、记录读取失败时，给出准确状态及可执行入口。
- 手机与电脑对同一份课程、同一项安排显示一致的已保存状态。

## 四 页面和用户流程

### 一个日常入口

英语模块默认进入“今日学习”，将其改为统一学习首页。首页突出一个主行动，按当前推荐显示“开始今天的学习”“继续上次学习”或“开始到期复习”，并说明将打开的课程、当前阶段和一句推荐理由。用户点击后直接进入内容，不再经过一层清单或报告。

原有词卡自评功能从首页“去学词”进入，词库、学习记录继续保留。导航中的“分析与巩固”保留为辅助入口，默认打开历史课程，另可切换今天、本周、本月报告；其中不再建设第二个日常学习清单。历史课程和报告都提供“返回今日学习”。统一入口不改变自评、课程与复测各自的统计口径。未解锁时主行动为“解锁并继续”，公开词库仍可通过次级入口浏览。

首页只展开一项推荐。“其他可学内容”折叠展示全部可执行内容，“历史课程 N 份”始终可访问。需要准备材料的事项单列在次级区域。有其他可学内容时，不让备课提示挡在学习前面。携带具体课程链接进入时仍直达该版本；未解锁则先解锁，成功后返回原目标。

### 日常主流程

普通课程：**打开英语首页 → 开始或继续 → 学讲解 → 读短文 → 做练习 → 看结果并确认复习 → 结束。**

到期复测：**打开英语首页 → 开始到期复习 → 先独立答新题 → 看解释与结果 → 确认后续安排 → 结束。**

页面始终显示当前步骤。普通课程使用“1 学讲解、2 读短文、3 做练习”，完成后显示“本次结果”和“本次结束”；复测使用“先答题，再看解释”。练习显示“第 N 题，共 M 道有效题”，待核对题另行说明。已完成步骤可回看，但进入练习后回看教学内容须按第五节标记辅助，不改写此前独立提交的答案。

每个学习页面在主要操作附近回答四个问题：现在学什么、这一步要做什么、操作是否已保存、接下来去哪里。保存反馈就近显示，不仅依赖短暂弹出的提示。正文使用“读短文”“到期复习”等直白词语，版本、截止时间和统计口径放在详情中。

### 每一步的操作与去向

| 页面或步骤 | 从哪里进入及当前任务 | 主要按钮 | 保存成功后 | 保存失败时 |
| --- | --- | --- | --- | --- |
| 解锁 | 首页或课程直达链接；访问个人学习内容 | 解锁并继续 | 进入原目标；无指定目标则回首页 | 留在输入处说明原因，不清空目标链接 |
| 统一首页 | 打开英语模块；确认系统推荐的下一项 | 开始今天的学习、继续上次学习或开始到期复习，三者择一 | 读取最新保存阶段，直接打开内容；此处不写学习完成记录 | 读取失败时给“重新读取”，不跳空白页、不显示为没有任务 |
| 学讲解 | 普通课程未完成讲解；阅读用法与例句 | 已读完，继续精读 | 保存讲解完成，进入短文阶段，提示“讲解进度已保存” | 留在本步骤，保留内容，提供“重试保存” |
| 读短文 | 讲解完成；阅读译文与句子拆解 | 已读完，开始练习 | 保存精读完成，收起教学内容，进入第一道未答题 | 不进入练习，保留阅读页面，提供重试 |
| 做练习 | 学习步骤已完成，或进入到期复测；逐题作答 | 提交答案 | 保存本题答案并显示解释；主按钮改为“下一题”，最后一题为“查看本次结果” | 保留本题选择及其他未提交内容，显示“尚未确认保存”，不显示答题成功或进入下一题 |
| 本次结果 | 有效题已答完；了解结果和下次建议 | 有建议时“按建议安排复习并结束”，无建议时“结束本次学习” | 有建议则保存确认结果，再进入结束页；无建议则直接结束，不生成额外完成记录 | 已保存答案保留；明确哪些安排成功、哪些未确认，只重试未确认部分 |
| 本次结束 | 从结果页完成操作；看到本次保存回执 | 返回今日学习，可不点击直接离开 | 可返回首页，不自动开启下一课，不把未做内容记为完成 | 此页不新增写入；尚未确认的安排应留在结果页处理 |

保存期间显示“正在保存”，禁止重复点击推进。只有服务器确认成功才推进；超时显示“尚未确认保存”，可按现有机制重试或读取已保存结果。不得为正常的步骤切换再增加一次确认弹窗。手机端同样明确显示当前步骤和主要按钮，长内容读完后无需返回页首寻找下一步；核心操作不依赖悬浮或横向滚动。

### 第一次使用与学词后的衔接

解锁后没有个人记录和课程时，首页说明“先认识一些词，记录哪些记得、哪些模糊”，主按钮为“开始学词”，直接进入现有词卡。每次自评保存成功后显示下一词，始终提供“本次先到这里”，不要求用户完成固定词数才能退出。

结束学词后，说明已保存的自评数量。已有适合的课程时提供“开始巩固”；有模糊或忘记记录但缺课程时提供“准备巩固材料”，进入下述准备说明；没有需巩固的依据时允许直接结束，不为了补齐流程生成薄弱结论。已有自评、存在需巩固依据但尚无课程的用户，首页主行动直接进入准备说明，无须重新做一轮自评。

### 结果页与结束反馈

结果页先回答三件事：本次完成了什么、哪些目标仍需练习、建议何时再来。首屏用自然语言说明结果；“独立作答”“辅助作答”“近期趋稳”等判定依据在详情中展开。正确题数与有效题数应可见，含提示的答案须标明，不能把辅助答对包装成独立掌握。

有多条复测建议时，先展示目标和具体日期，再用一次主操作确认当前尚未处理的建议，无须逐词点击相同的确认按钮。已有手工日期冲突的条目必须展开并明确选择后才能提交；“调整日期”作为次级操作。页面允许“本次不安排并结束”，明确将本次尚未处理的建议记为跳过，不改已确认安排，也不计为遗忘。部分保存成功时保留成功部分，用户可重试剩余项，或明确只跳过尚未接受的建议后结束，不能笼统宣告全部成功。超时或结果不明的项必须先读回或按现有防重复机制重试，确认实际保存状态后再决定；不能把“本地未确认”直接当成“服务器未保存”执行跳过。

安排保存后结束页显示实际日期，例如“下次打开时，可查看 10 月 14 日的复习安排”。若材料还没有准备好，同处注明“新题待准备”，不承诺届时一定可直接作答，也不暗示已经创建通知。结束页只是成功回执，用户可以直接离开，不要求再点击一次完成。页面提供一个次级入口“再学一项”，按最新推荐直接开始下一项；没有可执行内容时不展示该入口。日期均由实际数据产生，示例日期不写死。

### 中途暂停与下次回来

讲解、精读和练习均提供次级入口“先学到这里”。退出前说明最后一次已保存的阶段；尚未确认完成的阅读步骤，下次从本步骤继续，不承诺恢复到具体段落。未提交答案保留为未提交状态；存在保存结果不明的操作时，沿用已有重试或读回后取消流程，未确认成功前不能显示已保存。

下次打开首页，若没有优先的到期复测，主行动直接继续最近有已保存进度的课程。若到期复测优先，说明推荐理由，同时提供“继续上次课程”次级入口。用户进入某个步骤后，不因新的推荐出现而中途切走。

全部有效题已答完但本次复习建议尚未处理时，练习完成事实保持不变，首页仍将“继续确认复习安排”作为该内容的下一步，直接恢复结果页。普通课程和复测结果均适用；部分安排已保存时只处理剩余建议。此入口从答案、建议和已处理安排计算，不另存一份结果页完成状态。已处理全部建议或当前没有有效建议后，该内容才退出行动推荐。

跨设备只恢复已经保存的学习步骤、答案与安排。刚打开内容但没有保存任何步骤，不算已开始或已完成；未提交草稿不承诺跨设备同步。

### 缺少材料时的明确指引

首期仍需要在 Codex 中准备新材料，这是学习流程中的跨应用步骤。准备说明页应完整展示：

1. 点击“复制准备请求”，复制带目标词或复测安排的请求；复制失败时可手动选中完整文本。
2. 将请求粘贴给 Codex，要求按既有工作流生成、保存并读回。网站不会因复制动作自动开始生成。
3. Codex 确认保存完成后，点击其返回的课程链接，或返回网站点击“刷新学习内容”。
4. 读取成功且有可用材料后，显示“材料已就绪”和直接开始入口；复测尚未到期时显示可用日期，不允许提前作为正式复测提交。

有其他可学内容时，页面提供“先学已有内容”。完全没有材料时，用户仍可回到词库或结束；没有可用自评时引导先学词。刷新后尚未发现新材料，明确写“尚未读取到新材料”，保留请求和刷新入口；网络错误另行提示，不伪造准备进度、不宣称生成失败。

### 历史与分析的辅助入口

用户主动进入“分析与巩固”时，默认能看到历史课程；今天、本周、本月作为报告筛选，不参与日常必经流程。当对应周期没有报告时，显示“本期尚未生成分析”，同时提供历史课程数量与“返回今日学习”，不让空报告掩盖已有内容。

本周视图只展示本周报告，不将日课程伪装成周报告。历史、版本、截止时间和证据详情可查看，但默认不与主要学习动作争夺注意力。

历史入口保留完整的已保存分析内容。打开课程后可展开“查看当时的分析”，看到原报告结论、统计周期和截止时间；只看分析不写入学习完成事件。“没有本期报告”“没有任何历史课程”“当前筛选无结果”分别显示，不用同一句“暂无数据”代替。筛选无结果时提供“清除筛选”。

| 进入方式 | 返回行为 |
| --- | --- |
| 从首页主行动进入 | 返回今日学习；中断时说明已保存阶段 |
| 从历史课程列表进入 | 提供返回历史课程，保留本次搜索与筛选条件 |
| 从具体课程链接进入 | 直达指定课程版本，提供返回今日学习；解锁不丢失目标 |
| 从课程打开词条详情 | 关闭详情后仍在原学习步骤；不重置当前未提交选择 |

返回、关闭详情和切换筛选都不等于完成学习。未提交内容或结果不明的保存仍按已有恢复规则处理。

## 五 首期业务规则

### F00 词库掌握程度筛选

词库增加“掌握程度”，提供“全部程度、已掌握、模糊、忘记”，默认全部。筛选与搜索词、主题、类型、优先级、当前状态和日期条件取交集；改变筛选只影响展示，不写学习记录。

| 选项 | 判定口径 |
| --- | --- |
| 已掌握 | 词条当前状态为已掌握；可能来自自评或手工设置，不代表跨日验证通过 |
| 模糊 | 当前状态为学习中，且最近一次已保存自评为模糊 |
| 忘记 | 当前状态为学习中，且最近一次已保存自评为忘了 |
| 全部程度 | 不按掌握程度排除词条，包含未学和没有可用自评的旧数据 |

三类结果互斥。只有旧版状态、没有自评的学习中词条，不能猜测为模糊或忘记。用户手工改为已掌握后，不再因旧的模糊记录进入模糊结果；再次保存模糊或忘了的自评后，按新的已保存状态重新归类。页面提示“按当前状态与最近一次自评筛选”，没有记录时不伪造最近自评。

学习记录页复用该筛选时，筛选的是词条当前掌握程度，各行仍显示当时自评，不把历史答案改写为当前结果。两种口径在列表说明中明确区分。组合条件没有结果时显示“没有符合当前筛选的词条或记录”，提供“清除筛选”，不提示用户生成课程。未解锁时说明个人筛选需解锁，公开词库仍可浏览。

### F01 统一学习入口及每日行动推荐

**首页推荐是随已保存记录更新的行动建议，不是必须完成的打卡指标。** 默认展开一项主推荐，其余内容收在“其他可学内容”中，展开后可以直接选择，不限定当天可学数量。待办不会因跨日、未被主推或当天未完成而被删除、计错或自动延期。

可执行项按以下顺序排列：

| 优先级 | 候选项 | 点击后的行为 |
| --- | --- | --- |
| 1 | 已到期且有可用新语境材料的已确认复测 | 打开对应复测练习 |
| 2 | 已有保存进度，仍有学习步骤、题目或复习建议待处理的内容 | 恢复实际学习阶段；题目已完成但建议未处理时，直接进入结果页 |
| 3 | 关联近期反复不稳或近期需巩固词条的未开始普通课程 | 打开已有课程及选词依据 |
| 4 | 其他未开始的普通课程 | 打开课程；理由写“尚未学习”，不虚构薄弱诊断 |

同组排序建议：复测按约定日期从早到晚，再按用户词条优先级；待继续内容按最近一次已保存学习、作答或建议处理时间从近到远；重点课程先反复不稳，再近期需巩固，再按涉及词条的最高用户优先级；其他课程按生成时间从早到晚。所有并列情况采用稳定顺序，同一组事实刷新后不随机跳动。

主推荐只展开标题、当前要做的步骤、一句推荐理由、预计时长及主要按钮。目标词、完整依据与其他信息按需展开。按钮直接打开当前阶段，不先跳转长报告；推荐排序只在首页及一项结束后刷新，不打断正在学习的内容。

课程标注的时间只是估计，学习与练习分别说明；进行中课程不伪装成精确剩余时间，缺少估计时显示“时长未标注”。课程可能较长，始终允许停在当前阶段，下次继续，不承诺所有推荐都能在五分钟内完成。

推荐依据使用现有最近 30 个自然日的规则：反复不稳需要至少两个不同日期的不稳记录；近期需巩固依据最近一次有效自评或独立首次作答；近期趋稳沿用既有跨日证据门槛。卡片至少能展开所引用记录的日期、类型与结果。页面显示统计截至时间，未登录、无记录和读取失败分别处理。

**去重与边界：**

- 同一份课程即使覆盖多个重点词，也只生成一张卡片，合并推荐理由。
- 同一张复测练习覆盖多项安排时只显示一次，展开可查看关联安排；提交后仅更新实际完成的安排。
- 同一词出现于不同课程，不据此认定课程重复；不同含义或用法分别保留。首期只按课程或安排的明确关联去重，不引入语义相似度判断，也不自动合并不同课程。
- 一个已确认安排如有多个可用练习版本，优先继续已开始且仍有效的一份；均未开始则使用最新可用版本。完成后其他版本不再作为该安排的新待办，历史保留，并标注“该安排已在其他课程完成”，提供回看和打开完成版本的入口。受影响题目不再显示可提交状态；同一课程若还包含其他未完成安排，只继续其仍有效的部分。
- 今天没有自评记录，仍可推荐历史课程和已到期复测。没有可执行课程时：存在尚未被有效材料覆盖的备课依据则主推“准备巩固材料”，不存在则主推“去学词”；首次用户显示“开始学词”。已确认但未到期的复测展示约定日期，不开放正式提交；尚无材料可以提前准备，已有有效材料则不重复生成。用户始终可以结束，不强制生成课程。
- 被标记有误的题目不能作为新的可执行复测；课程中还有其他有效题时仍可继续，受影响部分显示待核对。

缺少材料的事项单独汇总，不挤走可以立即开始的课程。没有可执行内容且确实需要备课时，主行动进入第四节的准备说明。准备请求列明待处理词或已确认复测安排及目标用法；复制、等待用户操作、材料已保存三者明确区分，不制造网站正在后台生成的假象。

### F02 历史课程

默认展示全部已保存课程，按生成时间倒序排列。支持按标题或目标词搜索、按学习进度筛选，并按生成日期分组。分析周期与生成日期分别显示，不将两者混为同一天。

列表默认只展开课程标题、当前学习步骤、有效题已答数量和一个继续或回看入口，电脑和手机均采用这一层级。目标词、分析周期、内容截止时间、版本及复测摘要可在详情中展开。继续入口直接到当前步骤，不要求先阅读报告全文；无需用户判断该选哪个版本。

“待复测”属于独立筛选条件，不取代课程的学习进度。一门课程可以同时是“练习已完成”和“有到期复测”。同一词参与多门课程时，课程数量按保存的课程分别计算。

同一日期的版本号可能对应不同批次或不同主题，不能只保留最大版本号，也不能把较小版本全部视为已替换。只有明确的修正关系才展示“有修正版”，原课程、题目和答案继续可读；已保存进度不自动迁移到新内容。

### F03 课程进度与验证结果

以下状态由已保存事实计算，打开页面、点击查看和进入课程都不等于完成学习。

| 学习进度 | 判定条件 | 主操作 |
| --- | --- | --- |
| 待学习 | 普通课程有完整讲解，尚无讲解完成记录 | 开始学习 |
| 待精读 | 讲解已确认完成，精读未完成 | 继续精读 |
| 待练习 | 精读已完成，尚无有效题目首次答案 | 开始练习 |
| 练习中 | 已提交部分有效题目，仍有未答题 | 继续练习 |
| 练习已完成 | 有效题目至少一道，且每道均有已保存的首次答案 | 尚有未处理建议则继续确认复习安排，否则查看结果 |

旧版无讲解课程标注“旧版练习”，从练习阶段计算，不补造讲解、精读完成记录。专项复测同样从练习阶段计算，不强制先学习讲解。

题目被标记有误时，从当前有效题目分母中排除，另显示“有 N 题待核对”。全部题目都待核对时显示“待核对”，不能因有效题数为零而显示全部完成或通过。部分题待核对且其余有效题已答完时，显示“有效题已完成，部分题待核对”；受影响用法不获得通过结论。

课程进度之外保留以下事实，不合成为一个掌握分数。此表用于定义判定规则；用户首屏先看到当前任务、答题结果与下一步，详细判定通过“查看依据”展开，不并列堆放所有状态标签：

| 事实 | 判定与含义 |
| --- | --- |
| 已有课程 | 对应学习依据已经生成并保存完整课程，只说明材料已准备 |
| 练习已完成 | 有效题目已有保存的答案，答案可能错误或使用过提示 |
| 本次独立通过 | 该目标用法对应的有效首次答案均正确；提交前未使用提示或查看答案，普通课程进入练习后未回看影响该题的教学内容；不涉及待核对题，也没有本次仍模糊的反馈。普通课程按引导完成课前讲解与精读不影响独立资格 |
| 跨日复测通过 | 在已确认安排下，换语境、跨日、到期后首次独立作答通过 |
| 近期趋稳 | 同一词最后一次有效不稳后，至少两个不同日期有无提示首次单词级复测正确证据，其中一次距离该次不稳至少 7 天；沿用现有题目级证据规则，不等同于两项完整复测通过或该词所有用法已掌握 |

普通课程课前自由阅读讲解、译文与例句，不记为答题提示。进入练习后选择“回看讲解”时，入口旁先说明“回看后，尚未作答的题将记为辅助练习”，无需另加确认弹窗；回看或提示仅影响相应的未答题，已保存的独立答案保持原判定。专项复测先答新题，答前看讲解、译文或答案则按辅助处理，答后正常看解释不降低已提交答案的独立性。

任何上述结果都不自动改写词库中的“已掌握、学习中、未学”自评状态。多词理解题答错不能自动认定其中每个词都不会；需要单词级题目进一步验证。

### F04 跨日复测

复测继续沿用现有业务：练习有效题目完成后，对单词级错误、辅助作答或用户反馈仍模糊的目标提出建议；用户确认后成为有效安排。普通课程全对且无提示时，首期不额外新增强制复测任务，仍只说明当次表现。

初次建议为完成后的下一自然日；独立通过后分别建议在该次成功后的第 3 天、第 7 天复测。失败或辅助作答后回到短间隔建议。日期按北京时间计算，用户可调整或跳过；建议已过期时以确认当日为界提供下一自然日或更晚的可选日期，不要求选择过去日期。

| 安排状态 | 页面行为 |
| --- | --- |
| 未到期 | 展示日期；尚不开放作为正式复测提交 |
| 已到期且有材料 | 提供开始或继续复测入口 |
| 已到期但缺少材料 | 显示待准备材料和请求复制入口，不记录失败 |
| 本次作答已完成但未独立通过 | 显示实际结果，按规则提供下一次建议；不继续挂作原安排未完成 |
| 本次独立通过 | 显示通过及后续建议；达到既有阶段上限后不无限追加 |
| 已跳过 | 不作为到期任务，不记为遗忘，历史保留 |
| 关联题目待核对 | 暂停受影响用法的通过判断，提供待核对说明 |

材料必须关联已确认安排、目标词与目标用法，采用未用于该安排的新语境。重做旧题、提前练习或先看答案不计为独立复测通过；其他题已保存的独立结果不因后续查看讲解被改写。

完成一次安排与通过一次复测分别统计。已完成安排如果其题目后来被标记有误，保留原答案和标记，撤销受影响安排的有效完成证据及当前通过结论，并标注待核对。这沿用现有纠错规则；不把该题记为失败，也不让原有问题题目重新成为可执行待办。有另存的有效修正材料时可继续该安排，否则进入待准备材料，不能丢失原安排。

用户原有手工日期保持原值，确认专项复测时明确选择采用手工日期、建议日期或自选日期。结果页可按第四节用一次操作确认已展示的多条建议；这是合并用户操作，不改变逐条安排的业务身份与已保存结果。重复确认、重试和多设备提交沿用现有防重复机制。

## 六 内容生成与学习进度的边界

**首页突出一项，不等于每次只生成一项。** 本稿不改变原 PRD 中“处理本次全部未覆盖词条”的规则。

- 生成覆盖只回答：该次自评是否已有引用它的完整课程。学完与否另行记录。
- 已有课程未学完，不应为同一份未变化的依据重复生成，也不能阻止其他未覆盖词条备课。
- 用户授权一次全量生成时，仍处理该次读取结果中的全部 `generationCoverage.pendingWordIds`；可以分多节保存，但不能因首页只突出一项而截断或漏掉剩余词条。
- 首期不恢复短课 5 词、标准课 8 词的旧上限。课程较大时如实显示预计学习时长，用户可暂停继续。
- 需要生成跨日新题时，必须同时查看已确认复测需求；不能只因词条已有普通课程，就认定复测材料已齐备。
- 本稿只提供更明确的准备入口，不自动启动模型或修改现有生成任务。已授权的生成工作仍按原授权运行。
- 新材料保存并读回后，网站刷新即可纳入清单；仅有聊天草稿不能显示为可学习课程。

## 七 后续阶段的优化方向

以下是后续候选范围，不作为首期验收要求。需要实施时再细化规则和验收。

| 方向 | 预期体验 | 前提或限制 |
| --- | --- | --- |
| 完整词条档案 | 一个词串联自评、课程、答案、提示、反馈和复测时间线，并按用法区分 | 复用现有记录；旧数据没有的时间或行为不能补造 |
| 更细的错因分析 | 区分词义混淆、搭配、否定、条件、范围等问题，生成对应短讲解 | 细分类别需要明确的考查标签或可核对证据；AI 推断先标可能原因，再通过针对性题目验证 |
| 个人复习间隔 | 结合跨日独立作答，逐步调整下一次建议日期 | 积累不同间隔下的有效复测后单独评估；首期不宣称已经拟合个人遗忘规律 |
| 学习效果周报 | 展示相同目标用法的保持情况、反复不稳内容和下周建议 | 必须显示样本数与实际覆盖天数；不同题组的整体正确率变化不能直接解释为能力提升 |

首期不新增每题信心打分、学习计时器或复杂错误标签填写流程。优先使用已存在的自评、答案、提示和可选反馈，减少学习之外的操作。

## 八 数据与统计约定

| 统计项 | 口径 |
| --- | --- |
| 历史课程总数 | 实际保存的课程份数，包含可回看的旧版；不按日期或词条去重 |
| 有效题已答数量 | 当前有效题目中至少有一次保存答案的题数；重做不扩大分子 |
| 无提示首次正确率 | 有效题目的无提示首次答案中，正确题数除以总题数；分母为零显示暂无数据 |
| 到期未完成安排 | 用户已接受、约定日期不晚于今天且尚未完成的安排数；缺少材料也计入总量，并单列待准备数量 |
| 可执行复测卡片数 | 可立即开始的复测练习去重后的卡片数，可能小于其覆盖的安排数 |
| 推荐项完成 | 相应课程有效题已答完，或相应复测安排完成；与答对和独立通过分开，不另设每日打卡完成率 |

学习步骤只说明用户确认学过；估计时长不作为实际投入时间。未答不计错、跳过不计忘记、材料缺失不计失败。统计由固定程序产生，AI 解释需引用具体记录，并区分事实、推测与建议。

历史报告保留其原数据截止点和统计快照。当前清单、进度、待核对状态和复测摘要按最新保存事实计算，并明确属于当前状态；不得悄悄改写旧报告正文。

只读取生成或展示所需的个人学习数据，私人笔记默认不进入 AI 分析，口令和数据库连接信息不出现在文档、页面或生成材料中。

## 九 验收标准

以下为首期验收场景。应验证用户操作、保存结果和重新读取后的业务状态，不以单纯页面展示或接口成功代替完整验收。

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| B01 | 今天无报告，但历史已有 15 份课程 | 英语首页提供可学习的主行动和历史入口；分析与巩固默认显示历史课程，全部 15 份可访问，今天空报告不阻断学习 |
| B02 | 没有个人数据、未解锁、读取失败 | 分别显示暂无记录、解锁提示、读取失败，不显示虚假零记录或掌握结论 |
| B03 | 同时有到期可执行复测、进行中课程、重点未学课程 | 首页只展开一个按规则选出的主行动，一次点击直达内容，其他内容可展开；继续上次课程的次级入口可用 |
| B04 | 多项复测到期但没有材料，另有可学习课程 | 缺材料项单列，主行动仍为可开始的课程；用户无需先处理备课请求 |
| B05 | 同一课程关联多个薄弱词或同一复测课关联多个安排 | 只显示一张课程卡片，依据和安排不丢失，完成数量按实际保存事实计算 |
| B06 | 同一词存在不同用法课程，或同日有多批版本 | 不因词相同、日期相同或版本较小而隐藏课程；只按明确课程或安排关联去重 |
| B07 | 完成讲解后退出，换设备继续 | 显示待精读并恢复对应阶段；未提交的选择不算保存完成 |
| B08 | 精读完成但未答题，之后只提交部分答案 | 依次显示待练习和练习中，不提前显示已通过 |
| B09 | 所有题已答，但包含错误或使用提示后答对 | 可显示练习已完成；受影响用法不显示独立通过，首次统计不被重做改变 |
| B10 | 部分题或全部题标记有误 | 待核对数量单列；有效分母正确；全部待核对不显示全对或完成，历史答案保留 |
| B11 | 打开无学习单元的旧版课程 | 标注旧版练习，可回看和继续；不补造学习步骤 |
| B12 | 同一安排有多个材料版本，在一个版本中完成 | 其余版本退出该安排待办，显示在其他课程完成并链接完成版本，受影响题目不再提供提交入口；其他有效安排可继续，不产生重复完成数 |
| B13 | 用户确认、调整或跳过复测建议，有原手工日期 | 选择明确；未确认不新增安排；手工日期不被静默覆盖；跳过不计遗忘 |
| B14 | 普通练习全对无提示，或多词理解题答错 | 前者只说明当次表现，不自动宣告跨日掌握；后者不批量认定所有关联词错误 |
| B15 | 当天重做旧题、提前作答、先看提示后答对 | 均不计为跨日独立复测通过；合法到期新语境作答可按结果判定 |
| B16 | 复测失败、辅助完成或独立通过 | 原安排是否完成与是否通过分别显示，后续建议使用既有间隔并由用户确认 |
| B17 | 已通过复测的题目后来标记有误 | 受影响安排的有效完成与当前通过结论撤销，答案和历史报告保留；原题不重新推荐，有有效修正材料可继续，否则待准备，不记失败 |
| B18 | 同一词最后一次不稳后，在两个不同日期有无提示首次单词级复测正确证据，其中一次间隔至少 7 天 | 可显示近期趋稳，不宣称已完成两项完整复测；再次不稳后重新纳入巩固，原自评状态不自动修改 |
| B19 | 首页只主推一项，一次生成仍有更多未覆盖词 | 生成流程继续覆盖该次全部待处理词；已有未完成课程不重复生成、不阻止其他词备课 |
| B20 | 报告没有新内容，但新增了答案、反馈或复测结果 | 当前清单和状态更新，旧报告内容与截止点保持原样 |
| B21 | 跨北京时间午夜、网络重试或双设备提交 | 到期判断准确，已保存进度可读回，不重复增加答案、学习步骤或复测安排 |
| B22 | 仅有 3 个学习日自评且尚无答案 | 展示自评依据和实际覆盖日期，正确率显示暂无数据，不输出个人遗忘概率或确定能力诊断 |
| B23 | 首次解锁且无记录、无课程 | 首页主推开始学词，保存自评后可随时结束；按已有材料或备课需求给一个明确下一步，不显示虚假生成状态 |
| B24 | 普通课程从讲解推进到精读、练习，任一步保存失败 | 每步一个主要按钮，成功后直接进入下一步并反馈已保存；失败停留并保留输入，可重试且不重复记录，不要求再次确认正常转场 |
| B25 | 用户按普通课程引导先学讲解、精读，然后独立答题 | 课前学习不算提示；练习后回看只影响相应未答题，答后看解释不改已提交结果 |
| B26 | 多条建议中存在手工日期冲突，或一键确认时部分成功及超时 | 先明确冲突选择；超时项先读回或防重复重试确认状态，已成功项不改；仅确定未接受的建议可跳过，未全部处理前不宣告安排完成 |
| B27 | 练习结束并安排复习，或选择本次不安排 | 显示实际结果和保存回执，成功后已可离开，不再要求点完成；无建议不写多余记录，可选再学一项，未准备材料有明确说明 |
| B28 | 中途停止、跨日重进或新复测到期 | 首页直接打开已保存阶段或推荐到期复测，并保留继续上次入口；学习途中不被重排打断，不承诺恢复未保存草稿或具体阅读段落 |
| B29 | 仅有需备课内容，复制请求后又返回刷新 | 明确复制给 Codex、保存完成后回来刷新的步骤；复制不算生成，未发现材料与网络错误分开；新内容可用后能直接开始，无须到历史列表找版本 |
| B30 | 未解锁时打开具体课程链接，或在手机上操作 | 解锁后返回原目标；主按钮清晰可见，详情按需展开；核心流程不依赖悬浮操作或横向滚动，公开词库仍可访问 |
| B31 | 普通练习或复测已答完，但未处理建议或仅保存部分安排就关闭 | 下次首页保留继续确认复习安排入口，直接恢复结果页，已保存部分不重复确认；全部建议处理后才退出推荐，练习完成事实不被撤销 |
| B32 | 词库选择已掌握、模糊、忘记，并与其他条件组合 | 按 F00 口径取交集，三类互斥；新自评保存后刷新归类；未知旧数据不误归类，筛选不写学习记录 |
| B33 | 当前筛选无结果，或在学习记录页按模糊筛选 | 无结果可清除筛选；历史行保留当时自评，说明筛选依据是当前程度；未解锁不将个人数据当作零记录 |
| B34 | 从历史筛选结果打开课程、查看当时分析、打开词条后返回 | 当时报告可回看且不写学习完成；返回保留本次历史筛选，关闭词条不重置学习步骤与当前选择 |
| B35 | 首次使用者在没有口头指引时完成下述流程走查 | 能找到主动作、判断保存结果、完成或暂停，并知道下次从哪里继续；需要旁人解释才能继续的步骤记为体验缺陷 |

本地验证、部署完成和线上验收分别记录。上线验收至少从英语首页走通“直接继续 → 讲解与精读逐步保存 → 完成有效题 → 确认复习并结束 → 下次首页进入到期新题 → 保存答案 → 刷新及另一设备读回”，并检查首次学词、缺材料、保存失败和题目待核对分支。未来日期及异常场景在隔离验收数据中验证，不修改生产学习记录模拟时间。

流程体验单独验收：审核者不依赖口头解释，仅凭页面文字应能找到当前主动作，完成一次学习并知道下次如何继续。普通课程不要求先进入报告或选择版本，除必要的日期冲突选择外不重复确认同一决定；每个保存失败点都有明确恢复入口。

按以下任务在手机和电脑各走查一次，记录实际操作与卡住的位置，不预先告诉审核者应该点哪个按钮：

1. “今天学一点英语。”已有材料时，从首页一次点击进入当前应学阶段，完成一课并看懂结果与下次日期；首次无记录时，可以学几个词后结束。
2. “继续上次没学完的内容。”从已保存阶段恢复；如果首页主推到期复习，仍能找到继续上次的入口。
3. “找以前的分析，再复习模糊的词。”能访问历史分析与原课程，能在词库筛选模糊，理解自评与复测结果的区别。
4. “保存超时，或复习还没有题目。”能分清未确认保存和待准备材料，找到重试或准备说明；复制请求后不会误以为网站已开始生成。

通过条件：上述任务均可仅凭页面完成，保存失败不丢失当前输入、不产生重复记录；结束页无需再点完成，暂停后不会误报学完。发现阻断时修正对应入口或文案，不以新增教程页替代主流程修复。

实际学习改善另行观察：是否开始完成已有课程、是否按安排参加复测、同一目标用法是否出现跨日保持证据。首期不承诺正确率提升幅度，也不以生成课程数量当作学习效果。

## 十 实施边界与精简原则

首期复用现有词条、自评、课程、学习事件、答案和复测安排。清单、进度及数量优先从这些事实计算，不另建需要与原记录同步的每日任务副本，不给每个阶段额外增加一套手工状态。

推荐先用明确排序规则，不引入综合能力分数、推荐模型或个人遗忘曲线。继续使用既有课程详情、词条详情、保存与读回流程，不另做报告编辑后台或通用任务系统。只建设一个日常学习首页，不再复制一套分析内清单；每步保存与推进合并为一次操作，结束页只展示成功回执，版本与证据按需展开。掌握程度直接复用当前状态和最新自评，不新增一份需要同步的掌握等级。

允许新增必要的展示与查询能力；具体接口、存储和代码改动由审核后的技术方案确定。技术方案必须说明如何复用已有能力，以及每个新增字段是否确有不能从现有记录得到的事实。原有待提交代码与本 PRD 的首期范围分别管理。
