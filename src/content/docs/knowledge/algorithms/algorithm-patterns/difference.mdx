## 三种量不要混在一起

- 原数组 base[i]：修改前的值。
- 差分 diff[i]：从位置 i 起，累计值要改变多少。
- 还原值 active：走到 i 时，把之前的变化全部累加后的结果。

若 diff 是**原值的相邻差**，累计得到最终值；若 diff **只记录新增影响**，累计后还需加回 base[i]。第一课采用前者，第三课用后者记录字母位移。

闭区间 [l,r] 在 l 进入、r+1 退出；半开区间 [start,end) 在 start 进入、end 退出。先明确题意，不能机械背一个 r+1。

## Java 模板与工程边界

基础材料中的 `DifferenceArray` 提供 dirty 缓存：更新 O(1)，更新后首次单点查询触发 O(n) 还原，之后直到下次更新的单点查询 O(1)。`snapshot()` 即使缓存有效也要复制数组，仍是 O(n)。本课程把批量打标和统一还原显式拆开，方便观察。

连续更新再集中查询适合差分；每次更新后立即查询会反复扫描。动态需求需另选树状数组或线段树。long 降低 int 溢出风险，但并非无限大；生产输入仍须满足数值范围。
