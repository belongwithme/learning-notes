## 学习目标与必要基础

你需要会读数组、基础循环和 Java 方法。不熟悉下标、历史区、键、频次、查询与更新也没关系，首课会逐一解释。

学习时试着回答三个问题：我在枚举谁？我需要查询什么？我消掉了哪一层重复工作？这里沿用材料中的“枚举状态表”作为问题模型的称呼；它不是一种新容器，具体可以使用 HashMap、频次数组或前后缀数组。

## 建议学习顺序

1. 读懂问题与样例，确认统计的是哪些下标对。
2. 手动走一遍暴力检查，再看如何用左侧频次替代重复扫描。
3. 在错误实验中观察自己为什么会被算进去。
4. 对照 Java，换一个样例独立推演，再做三道自测。
