## 问题与贯穿样例

原数组 **[2,−1,3]**，查询闭区间 **[1,2]**。下标从 0 开始，包含下标 1 和 2，答案是 **−1+3=2**。支持负数，区间必须非空。

本节静态例题始终使用这个样例。下方自定义输入只改变主演示及联动代码，错误实验与自测各有独立样例。

## 从重复累加到前缀差

暴力方法从 l 走到 r，读一个数加一次。单次短区间很直接，但许多重叠查询会反复累加同样的元素。

先把“从最左边开始”的累计和记下来：**P=[0,2,1,4]**。其中 P[3]=4 包含前 3 项，P[1]=2 只包含前 1 项。

要的区间 [1,2] 在大段 [0,3) 内。大段减掉左边多出的 [0,1)，就只剩 [1,3)，也就是原数组闭区间 [1,2]：**P[3]−P[1]=4−2=2**。共同左段会抵消，正数、负数都成立。

## 为什么是 n+1 和 r+1

P 的下标表示取了**多少个元素**，nums 的下标表示**第几个位置**。n 个元素有 n+1 个前缀边界，包括一个都不取的 P[0]。所以 P[i+1]=P[i]+nums[i]。

闭区间 [l,r] 含 nums[r]，右前缀必须取到 P[r+1]。左前缀 P[l] 刚好排除 nums[l]。公式为 **P[r+1]−P[l]**，不需要给从 0 开始的查询额外写分支。

## 正确性与复杂度账本

P[r+1] 与 P[l] 的公共部分恰好是 nums[0…l−1]，相减后只留下 nums[l…r]，不漏两端，也不多算区间外元素。

逐项查询长度为 m 的区间，读取并累加 m 项，时间 O(m)。前缀解法先花 **O(n)** 时间与 **O(n)** 空间建表，以后每次两次读取、一次相减，时间 **O(1)**。Q 次查询总体 O(n+Q)。对一次很短的查询，预处理未必划算；动画步数不代表性能倍数。

前缀构造期间未算出的格子显示 ?，不会用 0 冒充结果。原数组改动后必须重建受影响的前缀，本课只讨论静态查询。

## 错误实验：少一个 +1，会漏掉什么

独立固定样例 **[5]，闭区间 [0,0]**。正确答案 5。故意把 P[r+1] 写成 P[r]，得到 P[0]−P[0]=0，漏掉唯一的右端点。
